## History, not current status

[The archive](archive/README.md) retains selected methodology, protocol snapshots,
data lineage and frozen result reports, including their incomplete/withdrawn
warnings. Old three-judge and line-edit scores must not be relabeled as current
Astra-only or no-Gemini executable-agent results.

[The migration/removal index](ARCHIVE_MIGRATION.md) accounts for all former docs.
Local progress diaries, weekly status, task-specific repairs and deployment logs
remain in the separate original backup rather than the publication tree. Missing
runtime assets or local run records are not silently supplied by an archived link.
